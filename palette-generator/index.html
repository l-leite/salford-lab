What is a HEX value?

A HEX value is a short code for a colour, written as # followed by six hexadecimal characters: 0–9 and A–F. The first pair sets red, the second green and the third blue. Each pair runs from 00 (none) to FF (maximum), mixing the three light channels into an RGB colour.

For example, #D99473 means red 217, green 148 and blue 115: a warm terracotta. #000000 is black and #FFFFFF is white.

Copy the code into a colour picker to reuse the same colour in diagrams, layouts and other software. It is more precise than choosing by eye and helps keep your palette consistent across a project. If an app asks for RGB numbers instead, use the three numbers beside the code or the CSV export. Screens, colour profiles and printing can change how a colour looks, so proof your final output.

Adobe import instructions

InDesign: in the Swatches panel menu, choose Load Swatches and select the .ase file. Illustrator: in the Swatches panel menu, choose Open Swatch Library → Other Library and select the .ase file. Photoshop: in the Swatches panel menu, choose Import Swatches and select the .aco file. These are named RGB swatches; proof colours with your document’s colour settings. Adobe swatch guidance ↗

Revit import instructions · Dynamo required

Open a project in desktop Revit, then Manage → Dynamo. Create a graph in Manual run mode and add a Python Script node. Open the downloaded .py file in a text editor and paste its full contents into the node’s Python editor, replacing the starting code. Save the node and Run the graph. No node inputs are needed. The script creates named materials with shading colours and solid surface/cut fills in the Material Browser. Assign them to elements in Revit. Existing materials with matching names are kept. This creates graphics materials; render appearance assets are not included. Native Revit testing is pending.

SketchUp import instructions · desktop required

Open the Ruby Console in desktop SketchUp (under Extensions → Developer, or Window in older versions). Paste path = UI.openpanel("Select palette", "", "*.rb"); load(path) if path, press Enter, then select the downloaded .rb file. Find the colours under Materials → In Model and apply them with the Paint Bucket. Existing materials with matching names are kept. Undo reverses the import in one step. SketchUp for Web cannot run Ruby scripts. Native SketchUp testing is pending.

AutoCAD instructions

Run SCRIPT in desktop AutoCAD and select the downloaded .scr file. Set objects to ByLayer to use the colours. Check your plot style before printing. Native AutoCAD testing is pending.

Think before choosing

Choose colours that support your argument and evidence. Check the hierarchy in greyscale, at the final size and in print.

Colour and hierarchy

Use different hues for categories, a light-to-dark scale for quantities, and a divergent scale for values on either side of a midpoint.

Give a main road a stronger orange and a heavier line; use pale yellow and a fine dashed line for a quiet path. Keep the same meanings across drawings.

Pastels work best as filled areas with dark labels. Use line weights, patterns and symbols as well as colour. Check the drawing in greyscale and print a proof.

A starting point

Test the palette in your own drawing. Change a colour, combine palettes or break a convention when it makes your ideas clearer. Judge the result at the size it will be read, on screen and in print. This generator offers a starting point; your judgement should take it further.
