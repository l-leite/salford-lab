# Think, Make, Show — Modes of work

Published at https://studio.salford-lab.xyz/tms-guide/.

The self-contained `index.html` includes sixteen spatial strategies, 21 examples
(seven per mode pair), mode-pair filters, process vocabulary and a print layout.
The examples explore community work, shared resources, creative production and
concentration, with suggested spaces and one leading architectural question per example.

Open the HTML file in a modern browser; no build step or installation is required.
Without JavaScript, all examples and the THINK + MAKE strategies remain visible.
The Print guide button prints all 21 examples, including when a filter is selected.
The header and footer link to the studio index when hosted in this repository.

`think_make_show_archetypes_codex_handoff.md` is an earlier working reference;
its example list predates this revision. Use the current guide and assessment brief.

Mode-pair and theme filters work together. Select an active theme again to clear it; All 21 resets both filters. Printing includes all examples. Area guidance is an indicative 500–750 m² gross external area (GEA). Students can add examples through the Padlet link in the final section.

The current catalogue has 21 consecutively numbered examples and one architectural question per example. The separate worked example has been removed. The highlighted GEA note explains total built area across all floors, including walls; the blue Padlet link invites student examples.
